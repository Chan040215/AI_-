### 新增

- Agent 支持通过 @ 引用当前画布、其他画布及全局素材，支持预览和多选。
- 选中节点后，可一键按水平、垂直或宫格排列。
- 图片、视频生成节点支持查看历史素材，并设为当前输出。
- 支持使用 AI 解读节点错误，提供排查建议（需配置文本模型）。

### 优化

- 提升长对话的滚动流畅度，支持快速回到最新消息。
- 历史消息支持在输入框中编辑重发，保留附件和素材引用。
- 优化大画布加载性能，提升 Agent 查找节点的效率。
- 首页支持直接选择工作目录，补充文件保存位置提示。
- 改善 Windows 版本更新的稳定性。

### 修复

- 修复 Agent 提问后重新发送消息可能受阻的问题。
- 修复部分生成失败提示不完整的问题，展示更具体的失败原因。
